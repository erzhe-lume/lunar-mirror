# 心镜 · Mirror Arcana

> 不是预言，是一面镜子。
> 抽三张牌，和此刻的自己谈一谈。

心镜是一款塔罗主题的自我对话应用。它借用塔罗的仪式感，把一次占卜变成一场有引导的自我追问：牌面提供观察角度，对话负责往下追一层，最后沉淀成可以日后回访的自省记录。

它不预测未来，也不替人做决定。应用会把「会不会 / 什么时候」这类问题重新框成「你正在如何面对这份不确定」，把落点交回给使用者。

## 特性

### 仪式与视觉

- **电影感开场**：牌堆从中央炸开成扇形，中心牌自行翻开，配合星象仪、浮尘与流光。
- **入场序列**：光缝点亮 → 月蚀镜门展开 → 牌从中心旋出 → 中心牌翻开、标题与星盘浮现，整段约 8 秒，可随时跳过，并尊重系统的「减少动态效果」设置。
- **分层夜空**：星云、极光、月蚀、行星环、椭圆轨道、雾层与星盘叠加成多层景深。
- **弧形命运之扇**：候选牌按屏幕宽度展示 9–15 张，沿半圆弧展开，底部带半圆金色基座，只凭直觉选三张。
- **扇形牌阵**：解读页把三张牌横向展开成一手小扇，中间一张居中略高，两侧向外倾斜，旁注位置、牌名、正逆位与关键词。
- **雾面镜室式对话区**：衬线字排版，半透明烟色玻璃底，边缘流动金边、四角刻线、缓慢环绕的星轨与雾气星点，顶部保留封章与菱形分隔。

### 牌库与解读

- **完整 78 张牌库**：22 张大阿卡纳 + 56 张小阿卡纳（权杖 / 圣杯 / 宝剑 / 星币），每张牌都有独立的正位与逆位牌义；抽牌有 50% 概率逆位 —— 逆位不是坏牌，是另一种方向。
- **两种解读模式，都完整可用**
  - **本心模式**（默认，无需 API Key）：牌义、主题识别、多轮追问、自省记录、签文与回访全部在本地生成，断网可用。
  - **模型模式**：支持 OpenAI 兼容、Anthropic（Claude Messages）、Google Gemini 三套协议，内置千问、OpenAI、Claude、Gemini、DeepSeek 预设，也可填写自己的网关地址。
- **多声部回答**：开场把处境、盲点、行动拆成三个各自说话的镜子，再补一条反方读法与「没有最终解释权」的收束；续聊并排给出两种可能，而不是把任何一句当成判决；问题里的第二层担忧（如「想学，但怕坚持不下去」）会被单独接住。
- **替他人开牌**：首页可选「自己 / 他人」并填写问卜者名字，抽牌、解读与时间线都会标注「为 XX 而开」。
- **留一个空白**：不写问题也能开始，整块首页可点击，带着一句默认的自省问题直接进入抽牌。
- **模型连通性检测**：保存前用当前配置发一条最小请求，验证 Base URL、API Key、模型名、跨域与返回格式并显示延迟；401、404、429、超时与 CORS 错误分别给出针对性提示。

### 记录与回访

- **自省记录**：对话收尾生成洞察、下一步邀请与四行本地牌面签文。
- **分享图导出**：签文可导出为 1080×1350 分享图或 1080×1920 竖版 Story 图。
- **时间线与镜面档案**：每条记录都可回访；「镜面档案」跨记录聚合反复出现的主题、词与牌，生成一封写给使用者的镜面来信。
- **可回退的页面历史**：镜面、时间线、抽牌与解读写入 hash history，浏览器返回键在应用内回退；草稿与进行中的解读会暂存，返回或刷新后仍可继续。

### 多模态与声音

- **朗读**：优先选用清亮女声（Natural / 晓晓 / 晓伊 / 瑶瑶），语速与音高调向更清楚、更轻的方向，长文按句合成，可在设置里试听并手动选择本机语音。
- **仪式音效**：洗牌、选牌、翻牌、生成记录各有轻量合成音。
- **氛围 BGM「镜室」**：默认关闭的无缝暗色背景音（低频 drone + 慢 pad + 远处铃声），可调音量，朗读时自动压低。
- **心情快照**：可附一张摄像头快照，随记录保存在本机。

### 本地优先

- 78 张牌、话术、字体、签文生成全部离线可用，无网络请求也能完成一次完整解读。
- 自省记录存于浏览器 IndexedDB，不经过任何服务器；进行中的解读与草稿存在 localStorage，刷新后恢复。
- 危机词会同时检查初始问题、追问、自省记录与回访；命中时自省页、时间线与分享图会隐藏三张牌面，改走安全分支。
- 摄像头在非安全上下文给出明确提示而不是白屏；根级 ErrorBoundary 兜底未捕获的渲染异常。

## 快速开始

环境：Node.js 20+（当前开发环境为 Node 24.22）。项目使用 Vite 6，请勿直接升级到需要 Node 22 的 Vite 8。

```bash
npm install
npm run dev
```

打开终端输出的本地地址即可。默认进入本心模式，不需要任何配置。

## 接入模型接口（可选）

1. 打开右上角「设置」，先选协议：OpenAI 兼容、Anthropic 或 Gemini。
2. 点一个服务商预设（千问 / OpenAI / Claude / Gemini / DeepSeek），或直接填写 Base URL、API Key 与模型名。Base URL 可以是 base 地址，也可以是完整端点。
3. 点「检测模型连通性」，用当前未保存的配置发一条最小请求。成功时显示延迟，失败时区分鉴权、地址 / 模型不存在、限流、超时与跨域问题。

开发与本地预览环境通过 `vite.config.ts` 中的同源代理转发，避开浏览器 CORS：

| 本地地址 | 转发到 |
| --- | --- |
| `/api/qwen` | DashScope `/compatible-mode/v1` |
| `/api/openai` | OpenAI `/v1` |
| `/api/anthropic` | Anthropic `/v1` |
| `/api/gemini` | Google `/v1beta` |
| `/api/deepseek` | DeepSeek `/v1` |

部署到静态托管时，自行实现同源代理并用环境变量覆盖预设地址：

```bash
VITE_QWEN_BASE=https://your-domain.com/api/qwen \
VITE_OPENAI_BASE=https://your-domain.com/api/openai \
VITE_ANTHROPIC_BASE=https://your-domain.com/api/anthropic \
VITE_GEMINI_BASE=https://your-domain.com/api/gemini \
VITE_DEEPSEEK_BASE=https://your-domain.com/api/deepseek \
npm run build
```

也可以直接在设置里把 Base URL 改成你的网关地址 —— 只要网关实现对应协议并允许浏览器跨域访问。

> API Key 只保存在本机 localStorage。公开部署时不要把 Key 写进前端，鉴权应放在服务端代理里。

## 使用流程

1. 开场动画结束后，在首页选择「自己」或「他人」，写下问题，可附一张心情快照。
2. 点「洗牌 · 抽三张」，凭直觉为处境、盲点、行动各选一张牌。
3. 进入「心镜」对话：先读开场解读，再逐轮回应；本心模式会给出三句开场建议。
4. 点「收拢这次对话 · 生成自省记录」，得到洞察、牌面签文与下一步邀请，可保存 4:5 签文图或 9:16 竖版 Story 图。
5. 在时间线里回访；「镜面档案」会总结多次记录之间反复出现的主题。

## 项目结构

```
src/
  views/        Home / Draw / Reading / Journal / Mirror
  components/   Intro, TarotCard, InsightCard, CameraModal, SettingsModal...
  data/         78 张牌库（22 大阿卡纳 + 56 小阿卡纳）
  lib/          多协议模型客户端（OpenAI / Anthropic / Gemini）、本心模式引擎、
                存储、语音朗读、签文图、文案工具
  types.ts      牌面、对话、记录、设置类型
scripts/        本心模式覆盖率测试与 5 万条本地压测
```

## 技术栈

- **React 19** + **TypeScript 5.8**，无状态管理库，状态走 Context 与自定义 hook。
- **Vite 6** 构建与开发服务器，`vite.config.ts` 内建五路同源代理。
- **原生 CSS** 分层组织（`index.css` / `theme.css` / `visual-polish.css` / `model-manager.css`），无 UI 框架。
- **Canvas + Web Audio**：签文图导出、BGM 与音效合成、摄像头快照。
- **IndexedDB + localStorage** 持久化，Hash 路由。
- **oxlint** 做静态检查。

## 测试

```bash
npm run build
npm run test:coverage
npm run stress:local
```

覆盖率测试用 esbuild 打包本心模式引擎，对 35 个不同领域与问法逐一生成开场、两轮回应与自省记录，检查空响应、缺少问句、主题命中率、三牌位多声部结构、回应段落数、拼接标点，并覆盖危机语句与跑偏的工具型请求。

`stress:local` 默认生成 50,000 条完整本心对话（每条含开场、两轮回应、自省记录与三句建议，共 250,000 次本地生成调用），另跑 500 条危机追问安全用例；结果写入 `stress-results/`：`latest.json` 为汇总，`*-cases.jsonl` 为逐条记录，`*-samples.json` 为全文样例。调整数量：

```bash
npm run stress:local -- --cases 100000
```

> 应用运行时的记录不是 JSON 文件：自省记录保存在浏览器 IndexedDB 的 `tarot-mirror` 数据库、`entries` store 中；设置保存在 localStorage 的 `tarot-mirror.settings` 键。它们位于浏览器配置目录内，由浏览器管理。

## 设计取向

- **先保证可用，再谈聪明**：本心模式保证断网、无额度、无配置时都有完整回应；模型模式负责开放域的细腻对话，并支持多协议与自定义网关。
- **不承诺预测**：所有模式都会把「会不会 / 什么时候」重新框成「你正在如何面对不确定」。
- **长记忆优先于单次炫技**：回访、时间线、镜面档案让一次对话有后半程，而不是一次性回答。
- **隐私本地化**：记录与快照默认不离开浏览器。

## 已知边界

- 本心模式是「本地主题识别 + 牌义 + 多声部语料组合」的引导系统，不是通用大模型；面对完全陌生的开放域问题，会回落到通用内省框架，而不是硬编答案。
- 语音输入暂未开放，提问以文字为主；朗读由浏览器语音合成提供，不经过模型接口。
- 朗读音色来自浏览器 / 操作系统。若系统只提供基础 SAPI 音色，效果偏机械 —— 建议用 Edge 或在系统里安装 Natural 语音，也可在设置中手动切换并试听。
- 摄像头快照需要浏览器授权，拒绝授权会显示提示，不影响主流程。
- 仪式音效默认关闭，开启后需浏览器允许播放音频；不支持 Web Audio 的环境会静默降级。
- 真实服务商的成功链路需要在各自有可用额度的环境中验证；仓库内已用本地 mock 验证 OpenAI 兼容、Anthropic、Gemini 三套协议的请求、解析、完整解读与连通性检测。

# 心镜 · Mirror Arcana

> 不是预言，是一面镜子。  
> 抽三张牌，和此刻的自己谈一谈。

「心镜」是面向千问创造力比赛的 AI 塔罗自省作品。它借用塔罗的仪式感，把一次占卜变成一场有引导的自我对话：牌面提供角度，AI 或本地引导负责追问，最后沉淀成可回访的自省档案。应用不预测未来、不替人做决定，目标是让人更清楚地看见自己正在纠结什么。

## 亮点

- **电影感开场**：牌堆从中央炸开成扇形，中心牌自行翻开，配合星象仪、浮尘和流光。
- **两种模式，完整可用**
  - **本心模式**（默认，不填 API Key 即可）：牌义、主题识别、多轮追问、自省记录、签文和回访全部在本地生成，断网可用。开场与续聊采用多声部结构，不给出单一中心答案。
  - **多协议模型模式**：支持 OpenAI 兼容、Anthropic（Claude Messages）和 Google Gemini 三套协议，内置千问、OpenAI、Claude、Gemini、DeepSeek 预设，也可以直接填写自己的网关地址。
- **模型连通性检测**：保存前可用当前配置发送一条最小请求，验证 Base URL、API Key、模型名、跨域与返回格式，并显示延迟；401、404、429、超时和 CORS 错误会给出针对性提示。
- **多声部本心回答**：开场把处境、盲点、行动拆成三种各自说话的镜子，再补一条反方读法和“没有最终解释权”的收束；续聊会并排给出两种可能，而不是把任何一句当成判决。问题里的第二层担忧（如“想学，但怕坚持不下去”）也会被单独接住。
- **替他人开牌**：首页可选择「自己 / 他人」，填写问卜者名字；抽牌、解读和时间线都会显示「为 XX 而开」。
- **不提问也能开始**：首页「留一个空白」整块可点击，带着一句默认的自省问题直接进入抽牌；选择「他人」时会自动把称呼带进问题。
- **长期镜面**：每次记录都可日后回访；「镜面档案」会跨记录聚合反复出现的主题、词和牌，生成一封写给用户的镜面来信。
- **牌面签文**：每次自省自动生成四行本地签文，可导出为 1080×1350 分享图或 1080×1920 竖版 Story 图。
- **入场仪式**：光缝点亮 → 月蚀镜门展开 → 牌从中心旋出 → 中心牌翻开、标题与星盘浮现；整段约 8 秒，可随时跳过，也尊重系统的减少动态效果设置。
- **分层夜空**：星云、极光、月蚀、行星环、椭圆轨道、雾层和星盘叠加，不再是单色紫色加一个圆环。
- **三张牌的扇形牌阵**：解读页把三张牌横向展开成一手小扇，中间一张居中略高，两侧各自向外倾斜，底部带半圆托弧，旁边配位置、牌名、正逆位和关键词。
- **雾面镜室式回答框**：回答用偏书卷气的衬线字排版；对话区不再是一块硬边框，而是半透明烟色玻璃，边缘带流动金边、四角刻线、缓慢环绕的星轨、雾气与忽明忽暗的星点，顶部保留封章与菱形分隔。
- **轻甜朗读音色**：自动优先清亮女声（Natural / 晓晓 / 晓伊 / 瑶瑶），并把语速与音高调成更清楚、更轻的方向；也可在设置里试听并手动选择本机语音，长文按句合成。
- **仪式音效与氛围 BGM「镜室」**：洗牌、选牌、翻牌、生成记录有轻量合成音；另有默认关闭的无缝暗色 BGM（低频 drone + 慢 pad + 远处铃声），可调音量，朗读时自动压低。
- **多模态**：朗读回应、摄像头心情快照（快照随记录保存在本机）。
- **完整 78 张牌库**：22 张大阿卡纳 + 56 张小阿卡纳（权杖 / 圣杯 / 宝剑 / 星币），每张牌都有独立正位与逆位牌义；抽牌时 50% 概率逆位，逆位不是坏牌，而是另一种方向。
- **弧形命运之扇**：候选牌按屏幕宽度展示 9–15 张，沿更深的半圆弧展开，底部带一层半圆金色基座；牌虽然更多，仍然只凭直觉选三张。
- **本地优先**：78 张牌、话术、字体、签文生成全部离线；记录存于浏览器 IndexedDB，不上传服务器。进行中的解读会暂存到 localStorage，刷新后能恢复对话与自省页。
- **安全与恢复**：危机词会同时检查初始问题、追问、自省记录和回访；危机分支的自省页、时间线和分享图会隐藏三张牌图；摄像头在非安全上下文会给出明确提示而不是白屏；根级 ErrorBoundary 负责兜底未捕获的渲染异常。
- **可回退的页面历史**：镜面、时间线、抽牌和解读会写入 hash history，浏览器返回键在应用内回退；进行中的解读和草稿会暂存，返回或刷新后仍可继续。

## 快速开始

环境：Node.js 20+；当前环境为 Node 24.22，项目仍使用 Vite 6（请勿直接升级到需要 Node 22 的 Vite 8）。

```bash
npm install
npm run dev
```

打开终端输出的本地地址即可。默认进入本心模式，不需要任何配置。

### 接入模型接口（可选）

1. 打开应用右上角「设置」，先选择协议：OpenAI 兼容、Anthropic 或 Gemini。
2. 点一个服务商预设（千问 / OpenAI / Claude / Gemini / DeepSeek），或直接填写你的 Base URL、API Key 与模型名。Base URL 可以是 base 地址，也可以直接填完整端点。
3. 点「检测模型连通性」。它会用当前未保存的配置发一条最小请求，成功时显示延迟，失败时会区分鉴权、地址 / 模型不存在、限流、超时和跨域问题。
4. 开发与本地预览环境通过 `vite.config.ts` 中的同源代理转发，避免浏览器 CORS：

| 本地地址 | 转发到 |
| --- | --- |
| `/api/qwen` | DashScope `/compatible-mode/v1` |
| `/api/openai` | OpenAI `/v1` |
| `/api/anthropic` | Anthropic `/v1` |
| `/api/gemini` | Google `/v1beta` |
| `/api/deepseek` | DeepSeek `/v1` |

5. 部署到静态托管时，请自行实现同源代理，并用环境变量覆盖预设地址，例如：

```bash
VITE_QWEN_BASE=https://your-domain.com/api/qwen \
VITE_OPENAI_BASE=https://your-domain.com/api/openai \
VITE_ANTHROPIC_BASE=https://your-domain.com/api/anthropic \
VITE_GEMINI_BASE=https://your-domain.com/api/gemini \
VITE_DEEPSEEK_BASE=https://your-domain.com/api/deepseek \
npm run build
```

也可以直接在设置里把 Base URL 改成你的网关地址；只要网关实现了对应协议并允许浏览器跨域访问即可。

> Key 只保存在本机 localStorage。公开部署时不要把 Key 写进前端，应该由服务端代理鉴权。

## 使用流程（现场演示）

1. 开场动画结束后，在首页选择「自己」或「他人」。
2. 写下问题，可附一张心情快照。
3. 「洗牌 · 抽三张」，凭直觉为处境、盲点、行动各选一张牌。
4. 进入「心镜」对话：先读开场解读，再逐轮回应；本心模式会提供三句开场建议。
5. 点「收拢这次对话 · 生成自省记录」，得到洞察、牌面签文和下一步邀请，可保存 4:5 签文图或 9:16 竖版 Story 图。
6. 时间线里可以回访；「镜面档案」会总结多次记录间的反复主题。

## 项目结构

```
src/
  views/        Home / Draw / Reading / Journal / Mirror
  components/   Intro, TarotCard, InsightCard, CameraModal, SettingsModal...
  data/         78 张牌库（22 大阿卡纳 + 56 小阿卡纳）
  lib/          多协议模型客户端（OpenAI / Anthropic / Gemini）、本心模式引擎、存储、语音朗读、签文图、文案工具
  types.ts      牌面、对话、记录、设置类型
scripts/        本心模式覆盖率测试与 5 万条本地压测
```

## 测试

```bash
npm run build
npm run test:coverage
npm run stress:local
```

覆盖率测试会用 esbuild 打包本心模式引擎，对 35 个不同领域与问法逐一生成开场、两轮回应和自省记录，检查空响应、缺少问句、主题命中率、三牌位多声部结构、回应段落数、拼接标点，并覆盖危机语句和跑偏的工具型请求。

`stress:local` 默认生成 50,000 条完整本心对话（每条包含开场、两轮回应、自省记录和三句建议，共 250,000 次本地生成调用），另跑 500 条危机追问安全用例；结果写入 `stress-results/`：`latest.json` 是汇总，`*-cases.jsonl` 是逐条记录，`*-samples.json` 是全文样例。需要调整数量时运行：

```bash
npm run stress:local -- --cases 100000
```

> 应用本身的记录不是 JSON 文件：自省记录保存在浏览器 IndexedDB 的 `tarot-mirror` 数据库、`entries` store 中；设置保存在 localStorage 的 `tarot-mirror.settings` 键。它们位于浏览器配置目录内，由浏览器管理。

## 60 秒演示脚本

- **0–8s**：刷新页面，让牌扇炸开。「我们不是做一个更准的算命器，而是用塔罗的仪式感，让人愿意停下来看看自己。」
- **8–20s**：选择「他人」，输入「小雅」，问一个偏冷门的问题，例如「我总梦到过世的奶奶，是她在提醒我吗？」
- **20–35s**：抽三张牌，展示翻牌和「牌已入位」；重点说明本心模式不联网也能完成。
- **35–50s**：展示对话、快速回复按钮和追问；说明每条回应只问一个问题，不预测结果。
- **50–60s**：生成自省记录，展示牌面签文，保存分享图；收尾：「一次占卜结束，但镜面档案会把几次照见连成一条路。」

## 设计取舍

- **先保证不会翻车**：本心模式保证断网、无额度、评委临时提问时都有完整回应；模型模式负责开放域的细腻对话，并支持多种协议与自定义网关。
- **不承诺预测**：所有模式都会把「会不会 / 什么时候」重新框成「你在如何面对不确定」。
- **长记忆优先于单次炫技**：回访、时间线、镜面档案让作品区别于一次性 prompt 壳子。
- **隐私本地化**：记录和快照默认不离开浏览器。

## 已知边界

- 本心模式是本地主题识别 + 牌义 + 多声部语料组合的引导系统，不是通用大模型，也不是真正意义上的去中心化数据网络；面对完全陌生的开放域问题，会使用通用内省框架而不是硬编答案。
- 语音输入当前暂未开放，提问以文字为主；朗读仍由浏览器语音合成提供，不经过模型接口。
- 朗读音色来自浏览器/操作系统；如果系统只提供基础 SAPI 音色，效果会偏机械，建议用 Edge 或在系统里安装 Natural 语音，也可以在设置中手动切换并试听。
- 摄像头快照需要浏览器授权，拒绝授权会显示提示，不影响主流程。
- 仪式音效默认关闭，开启后需要浏览器允许播放音频；不支持 Web Audio 的环境会静默降级。
- 真实服务商 Key 的成功链路需要在各自有可用额度的环境中验证；仓库内已用本地 mock 验证 OpenAI 兼容、Anthropic、Gemini 三套协议的请求、解析、完整解读与连通性检测。
